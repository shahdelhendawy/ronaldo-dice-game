
# Ronaldo Dice Game

A simple Flutter dice game inspired by Cristiano Ronaldo.

## Features

- Roll two dice to generate random numbers.
- Display the total of both dice.
- Show a reaction image based on the result.
- Win when the total is 10 or more.
- Reset the dice values and start again.

## Technologies

- Flutter
- Dart

## Project Structure

```text
ronaldo-dice-game/
├── assets/
│   └── images/
├── lib/
│   ├── main.dart
│   └── dice.dart
└── pubspec.yaml
```

## How to Play

1. Press Roll Dice to roll both dice.
2. Check the total.
3. Reach a total of 10 or more to win.
4. Press Reset Game to start again.
